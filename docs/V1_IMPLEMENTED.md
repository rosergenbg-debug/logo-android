# Реализовано в v1.0

- DAF 0–250 мс с шагом 5 мс
- 48 кГц mono PCM16
- выбор входного и выходного Android audio device
- Bluetooth Classic / BLE routing через Android API
- режим встроенного микрофона телефона с Bluetooth-выходом
- профили задержки и громкости
- локальная обработка без записи голоса
- Sony WF-1000XM6 и WF-C710N как основные тестовые устройства
